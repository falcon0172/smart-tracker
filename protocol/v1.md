# Smart Tracker BLE Protocol Specification — v1.0

This document defines the binary Bluetooth Low Energy (BLE) v1 contract between the Seeed Studio XIAO nRF52840 Sense peripheral and the Smart Tracker mobile app central.

---

## 1. Overview & Constraints

- **Frame Size**: Fixed **20 bytes** per frame across all characteristics.
- **Endianness**: **Little-endian** for all multi-byte numbers (`uint16`, `uint32`, `int16`).
- **MTU Assumption**: Base 23-byte GATT MTU (20-byte payload + 3-byte ATT header). No assumption of negotiated MTU expansion.
- **Data Encoding**: Raw binary bit-packed structures. Text formats (e.g. JSON) are strictly prohibited on the 50 Hz motion path.
- **Service & Characteristic Base UUID**: `9f7c0001-7b6a-4f7d-9e2a-3c1d5b8a6200`

## 2. UUID Definitions

| Characteristic | UUID | GATT Properties | Description |
| :--- | :--- | :--- | :--- |
| **Base Service** | `9f7c0001-7b6a-4f7d-9e2a-3c1d5b8a6200` | - | Primary Workout Tracker Service |
| **DeviceInfo** | `9f7c0002-7b6a-4f7d-9e2a-3c1d5b8a6200` | Read | Board hardware & protocol capabilities |

| **ControlAck** | `9f7c0006-7b6a-4f7d-9e2a-3c1d5b8a6200` | Notify | Firmware command acknowledgements |

## 3. Frame Layouts

### 3.1 Motion Frame (20 bytes, Notify)

| Byte Offset | Type | Field Name | Description |
| :---: | :---: | :--- | :--- |
| 0 | `uint8` | `protocolVersion` | Must equal `1` |
| 1 | `uint8` | `flags` | bit0: calibrated, bit1: sensor clipped, remaining bits reserved |
| 2–3 | `uint16` | `sequence` | Increments per scheduled sample (wraps at 65535) |
| 4–7 | `uint32` | `deviceUptimeMs` | Milliseconds since board boot (wraps at $2^{32}-1$) |
| 8–9 | `int16` | `accelX` | Milligravity ($1000 = 1.0\text{ g}$) |
| 10–11 | `int16` | `accelY` | Milligravity ($1000 = 1.0\text{ g}$) |
| 12–13 | `int16` | `accelZ` | Milligravity ($1000 = 1.0\text{ g}$) |
| 14–15 | `int16` | `gyroX` | 0.1 degree/second ($10 = 1.0\text{ deg/s}$) |
| 16–17 | `int16` | `gyroY` | 0.1 degree/second ($10 = 1.0\text{ deg/s}$) |
| 18–19 | `int16` | `gyroZ` | 0.1 degree/second ($10 = 1.0\text{ deg/s}$) |

### 3.2 DeviceInfo Frame (20 bytes, Read)

| Byte Offset | Type | Field Name | Description |
| :---: | :---: | :--- | :--- |
| 0 | `uint8` | `protocolVersion` | Must equal `1` |
| 1 | `uint8` | `capabilityMask` | bit0: motion notifications, bit1: set control/counting, bit2: calibration command |
| 2–3 | `uint16` | `sampleRateHz` | Configured sample rate (e.g. `50`) |
| 4–7 | `uint32` | `bootId` | Random uint32 generated upon each board reset |
| 8–11 | `uint32` | `stableDeviceId` | Board serial / unique project ID integer |
| 12 | `uint8` | `firmwareMajor` | Major version (e.g. `1`) |
| 13 | `uint8` | `firmwareMinor` | Minor version (e.g. `0`) |
| 14 | `uint8` | `firmwarePatch` | Patch version (e.g. `0`) |
| 15 | `uint8` | `reserved` | Reserved zero |
| 16–19 | `uint32` | `supportedProfileMask` | bit0: telemetry-only, bit1: dumbbell curl profile 1 |

### 3.3 SetState Frame (20 bytes, Read, Notify)

| Byte Offset | Type | Field Name | Description |
| :---: | :---: | :--- | :--- |
| 0 | `uint8` | `protocolVersion` | Must equal `1` |
| 1 | `uint8` | `state` | 0: idle, 1: counting, 2: paused, 3: ended, 4: calibrating, 5: calibrationFailed |
| 2–3 | `uint16` | `stateRevision` | Increments whenever set state or duration updates |
| 4–7 | `uint32` | `bootId` | Must match DeviceInfo boot ID |
| 8–11 | `uint32` | `wireSetId` | 0 = no set; active wire set ID assigned by app |
| 12–15 | `uint32` | `cumulativeReps` | Firmware authoritative detected reps |
| 16–19 | `uint32` | `activeDurationMs` | Active duration in milliseconds (excludes pause intervals) |

### 3.4 Control Frame (20 bytes, Write with response)

| Byte Offset | Type | Field Name | Description |
| :---: | :---: | :--- | :--- |
| 0 | `uint8` | `protocolVersion` | Must equal `1` |
| 1 | `uint8` | `opcode` | 1: START_SET, 2: PAUSE_SET, 3: RESUME_SET, 4: END_SET, 5: CALIBRATE, 6: SET_STREAMING |
| 2–3 | `uint16` | `commandId` | Rotating sequence ID generated by central |
| 4–7 | `uint32` | `expectedBootId` | Current boot ID verified by firmware |
| 8–11 | `uint32` | `wireSetId` | Nonzero wire set ID for set commands |
| 12–15 | `uint32` | `argument` | Opcode argument (e.g., profile ID for START_SET, 0/1 for SET_STREAMING) |
| 16–19 | `uint32` | `reserved` | Reserved zero |

### 3.5 ControlAck Frame (20 bytes, Notify)

| Byte Offset | Type | Field Name | Description |
| :---: | :---: | :--- | :--- |
| 0 | `uint8` | `protocolVersion` | Must equal `1` |
| 1 | `uint8` | `opcode` | Echoes control command opcode |
| 2–3 | `uint16` | `commandId` | Echoes control command sequence ID |
| 4–7 | `uint32` | `bootId` | Firmware boot ID |
| 8–11 | `uint32` | `wireSetId` | Firmware wire set ID |
| 12 | `uint8` | `resultCode` | 0: applied/already applied, 1: invalid state, 2: unsupported, 3: invalid arg, 4: wrong boot, 5: busy, 6: internal error |
| 13 | `uint8` | `currentState` | Firmware SetState after command evaluation |
| 14–15 | `uint16` | `reserved` | Reserved zero |
| 16–19 | `uint32` | `cumulativeReps` | Latest firmware rep count |

## 4. State Machine & Rules

1. **Rep Count Ownership**: Firmware owns detection. Receiving a Motion packet **NEVER** increments the rep count.
2. **Wire Set Keying**: Uniquely identified by `(stableDeviceId, bootId, wireSetId)`.
3. **Command Idempotency**: Firmware caches the last 32 commands. Identical retries return cached ACK without re-triggering transitions.
4. **Boot Continuity**: A boot ID change invalidates set continuity. Central must re-verify state on reconnect.
